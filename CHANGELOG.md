# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0]

### Added
- Single-page jewellery site: hero, marquee, collection, worn gallery, craft, stones, atelier, visit and footer sections.
- Product detail panel.
- English and Arabic localization with persisted language choice and RTL layout.
- Scroll-driven animations with reduced-motion support.
- Accessibility features: skip link, focus-trapped overlays, ARIA labels.
- Vercel deployment configuration.
