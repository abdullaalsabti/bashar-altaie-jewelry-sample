# Roadmap

Plans, not promises. Contributions are welcome via [issues](https://github.com/abdullaalsabti/bashar-altaie-jewelry-sample/issues/new/choose).

## Near-term
- Expand automated tests
- Improve component documentation
- Refine mobile responsiveness
- Improve keyboard accessibility
- Improve Arabic typography and RTL consistency

## Long-term
- Extract reusable bilingual UI components
- Provide configuration examples for adapting the template
- Add additional localization examples
- Improve performance and accessibility audits

## Known audit findings
See [docs/LIGHTHOUSE.md](docs/LIGHTHOUSE.md): colour contrast, list semantics, LCP image size, `robots.txt`.
