# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Report privately using GitHub's
[private vulnerability reporting](https://github.com/abdullaalsabti/bashar-altaie-jewelry-sample/security/advisories/new)
(Security tab → "Report a vulnerability").

Include a description, reproduction steps and potential impact. We aim to acknowledge reports within a few days, though this is a volunteer-maintained sample project and no response time is guaranteed.

## Supported versions

Only the latest commit on `main` is supported.
